# 食材搭配与食用禁忌常识

本篇整理食材搭配的常见疑问与真正需要注意的食用禁忌，区分"传统说法"与"有医学依据的注意事项"。

## 关于"食物相克"

1. "螃蟹与柿子相克""豆腐与菠菜相克"等流传甚广的说法，现代营养学与实验研究并未证实其普遍成立；更多是个体不耐受、食材不新鲜或一次食用过量所致。
2. 平台在荐菜与食养建议中，对"相克"类问题按"无可靠依据、注意适量与个人反应"口径回答，不夸大禁忌。

## 真正需要注意的搭配与禁忌

1. 服用华法林等抗凝药者：避免大量进食富含维生素 K 的食物（菠菜、西兰花等绿叶菜）的大幅波动，并遵医嘱定期监测。
2. 服用他汀类降脂药者：避免大量饮用西柚（葡萄柚）汁，可能影响药物代谢。
3. 酒精与头孢类药物：服药期间严禁饮酒，可能引发双硫仑样反应，属急症。
4. 空腹大量进食山楂、柿子等富含鞣酸的食物，胃动力差者可能形成胃石，应避免空腹过量。
5. 痛风急性期避免浓肉汤、酒精；糖尿病避免含糖饮品；高血压注意隐形盐（酱料、腌制品）。
6. 苦杏仁、生白果、发芽马铃薯、鲜黄花菜等含天然毒素，须规范加工或避免食用。

## 药食同源食材的慎用情形（常识）

1. 孕期慎用：山楂（活血）、薏苡仁、桃仁、红花等，食用前咨询医师。
2. 儿童不宜大量食用人参、鹿茸等大补类（非药食同源目录物质，平台不建议推荐）。
3. 脾胃虚寒者少食菊花、金银花、薄荷等偏凉花草茶。
4. 甘草、桔梗等长期大量食用与水钠潴留相关，高血压人群注意。

## 回答口径

涉及"XX和XX能不能一起吃"的问题：先区分是传统说法还是有循证依据的禁忌；给结论时附上适用条件（如服药、慢病、孕期），并提示个体差异。
