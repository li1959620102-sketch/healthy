# 特殊人群饮食注意（常识）

本篇覆盖孕期与哺乳期、老年人、儿童青少年等特殊人群的一般饮食原则，供平台食养方案与咨询回答参考。

## 孕期与备孕

1. 叶酸：备孕至孕早期每日补充 0.4 毫克叶酸（遵医嘱），多吃深绿叶蔬菜。
2. 孕中晚期适量增加鱼、禽、蛋、瘦肉与奶类；每周 2–3 次低汞鱼类。
3. 忌烟酒；限制咖啡因；避免生食（生鱼片、溏心蛋）与未充分加热的食品。
4. 山楂、薏苡仁、桃仁等药食同源物质孕期慎用；任何进补先咨询产科医师。

## 哺乳期

1. 增加优质蛋白与水分；汤类去浮油，避免以浓汤替代正餐。
2. 避酒；咖啡因限量；用药前告知哺乳状态。
3. 麦芽、韭菜等传统认为可能影响泌乳的食物，个体差异大，观察自身情况。

## 老年人

1. 足量蛋白质（鱼禽蛋奶豆）有助延缓肌少症，分散到三餐。
2. 关注钙与维生素 D：奶类、豆制品、适度日晒。
3. 食物宜软烂、少油少盐；独居老人注意防误吸（稀稠度适配）。
4. 多重用药老人新增任何药食同源补品前，建议核对药物相互作用。

## 儿童青少年

1. 规律三餐、吃好早餐；控制含糖饮料与零食，保证奶类摄入。
2. 儿童不宜使用成人"进补"类药食同源产品；调理由专业医师指导。
3. 培养多样化饮食，避免以甜食作为奖励。

## 通用提示

特殊人群的食养建议应与临床营养师或主治医师方案协同；平台内容为一般常识，出现疾病状态以医疗意见为准。
